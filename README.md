## 網站內容

- **號外**：三張童話新聞翻牌，選擇相信、不確定或轉傳後翻面看真相，最後帶出第三人效應
- **01 為什麼**：假訊息調查數據與第三人效應，滑入時數字滾動
- **02 理念**：五個體驗階段與三項特色
- **03 展區**：可點選的展場平面圖，顯示每一關的目的、體驗、設備與時間
- **04 查核員證**：出口收據示意與資料保護原則
- **05 對象與政策**：延伸受眾與《數位時代媒體素養教育白皮書》對應
- **06 時程與預算**：執行時程與經費分配
- **07 成效評估**：評估架構與指標
- **經費明細（budget.html）**：31 項經費依六大類別列出，含占比與總計

### 報告小功能

- 導覽列會依目前位置自動標示所在區塊
- 按導覽列的「簡報筆」或鍵盤 **L**，游標會變成雷射筆，方便報告時指重點

## 技術

- 純 HTML、CSS、JavaScript，共兩頁：`index.html`（提案）與 `budget.html`（經費明細），不需要安裝或建置
- 插圖以 base64 內嵌在檔案中
- 字體使用 Google Fonts（Noto Serif TC、Noto Sans TC、IBM Plex Mono）
- 部署於 GitHub Pages

### 在本機開啟

直接用瀏覽器打開 `index.html` 即可。

### 更新網站

1. 修改 `index.html`
2. commit 並 push 到 `main` 分支
3. 約 1–2 分鐘後，GitHub Pages 會自動更新
